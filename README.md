# Eröffnungstrainer

Schach-Eröffnungen gegen ein Eröffnungsbuch üben: 57 Eröffnungen mit über 220 Varianten, Zugerklärungen und Plänen fürs Mittelspiel.

**Chess.com-Analyse:** Benutzernamen eingeben, die Seite lädt die öffentlichen Partien und zeigt, gegen welche Eröffnungen man am häufigsten verliert und wo man vom Buch abweicht.

Live: https://sleepyslothyy.github.io/eroeffnungstrainer/

Verwendet [chess.js](https://github.com/jhlywa/chess.js) (BSD-2) und die cburnett-Figuren (GPLv2+).
